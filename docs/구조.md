# 템플릿 구조

```
저장소/
├── AGENTS.md                          Codex 자동 로드: 도메인 안전·운영·종료 정책
├── VISION.md                          불변 방향과 책임 경계
├── .codex/
│   ├── ACTIVE_ISSUE.example            로컬 활성 이슈 예시
│   ├── agents/                         planner·implementer·reviewer·build_recovery 역할
│   ├── playbooks/                      접수·흐름·계획·구현·리뷰·검증·빌드 복구
│   └── templates/                      STATUS·PROGRESS·GOAL·FEEDBACK·OUT_OF_SCOPE
├── docs/                               운영 문서와 PRD
├── workspace/{issue}/                  이슈별 장기 작업 메모리
└── tasks/todo.md                       현재 세션 계획과 검증 결과
```

`.codex/agents/` TOML 파일은 Codex가 프로젝트별 역할로 사용할 수 있는 설정이다. 역할 수보다 명확한 작업 계약과 독립 검증을 우선한다.
