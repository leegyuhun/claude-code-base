루프 층 요약 — 어떤 훅이 언제 도는가
─────────────────────────────────────────────────────────────────────

  PreToolUse   파일 수정 직전   .pas/.dfm 편집 차단 (사전 차단)
               Bash 실행 직전   위험 명령 6규칙 차단

  PostToolUse  도구 실행 직후   [짧은 루프] CP949 손상이면 exit 2로 즉시 교정 요구
                                .dfm 미동기 / .dpr 미등록 / 날짜 하드코딩은 경고

  Stop         턴 종료 시점     [긴 루프] 층 A 하네스 무결성은 항상 검사
                                PHASE 6 → 빌드 / PHASE 7 → 검증계약 잔여
                                실패 시 exit 2로 종료를 막고 행동 지시를 stderr로 전달
                                PHASE 8(수동 테스트 대기)은 무조건 통과
                                검증기 부재(build.bat·dproj 없음)는 실패가 아닌 통과

  PreCompact   컴팩션 직전      작업 좌표만 남김 (내용이 아니라 경로)

  상한에 걸리면 STATUS.md에 LOOP=halted 기록 → /next가 사유와 이력을 안내
  재개: python .claude/scripts/loop_state.py clear-halt
