# 템플릿 구조

```
repository/
├── AGENTS.override.md              Codex 자동 로드 진입 규칙
├── AGENTS.md                       Delphi·CP949·SQL·검증 정책
├── VISION.md                       불변 방향
├── README.md                       시작 안내
├── .codex/
│   └── ACTIVE_ISSUE.example         활성 이슈 파일 예시
├── docs/
│   ├── CODEX.md                    Codex 운영 안내와 요청 예시
│   ├── PRD.md                      요구사항 템플릿
│   ├── STATUS.md                   프로젝트 상태 참고 양식
│   └── 프로세스.md                  작업 흐름
├── workspace/{issue}/              이슈별 상태·진행 기록
└── tasks/todo.md                   현재 작업 계획과 검증 결과
```

Codex가 자동으로 읽는 파일은 `AGENTS.override.md`와 `AGENTS.md`다. 다른 문서는 해당 작업에 필요할 때 읽도록 지시하거나 요청에 포함한다.
